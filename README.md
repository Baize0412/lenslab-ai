# 垃圾分类助手

移动端单屏垃圾分类工具。拍照或从相册选图后，浏览器会使用 TensorFlow.js COCO-SSD 识别常见物品，并给出投放提示。图片只在设备上处理，不上传服务器。

网站：https://baize0412.github.io/lenslab-ai/

## 使用方式

手机上直接打开网站，点击“拍照识别”或“相册选图”。选图后自动识别；点击“重拍”可清除当前照片。首次使用需要联网下载识别模型。

轻触主画面会请求前置摄像头权限，允许后持续识别镜头中的常见物品；点击“停止”关闭摄像头。切换到其他页面或选择照片后，摄像头自动停止。实时画面同样只在设备上处理。

## 分类范围

当前模型仅能识别 COCO 数据集中的部分常见物品。水果和蔬菜、部分食物、书本及电子产品会给出相应分类提示；瓶子、餐具等材质不明的物品会要求人工确认。分类建议不是当地官方投放规则，需要结合材质、污染情况及所在地规定。

## 本地运行

```bash
python3 -m http.server 4173
```

打开 http://localhost:4173 。GitHub Pages 工作流位于 `.github/workflows/pages.yml`。
